# SHKit 许可合规与闭源商用说明

> 面向"自己写的代码用 MIT、但要闭源商用"的场景，说明 GUI 技术栈选型、
> LGPLv3 的具体义务与落地做法。
>
> **免责声明：本文由开发者整理，旨在协助合规，不构成法律意见。**
> 正式商业发行前请自行核对官方文档或咨询专业人士。
>
> 标注约定：
> - 【本机实测】= 在你这台机器的 Anaconda 环境里实际运行验证过的结论（最硬）；
> - 【通行做法】= LGPL/开源社区的公认做法，但本文未附条款原文链接；
> - 【待核对】= 建议正式发行前到官方页面确认一遍的点。

## 0. 一页速查

| 问题 | 结论 |
| --- | --- |
| PyQt5 能不能闭源商用？ | **不能**（GPL v3 / 商业双许可），除非购买商业许可 |
| PySide6 能不能闭源商用？ | **能**，走 LGPLv3 分支，满足下面 5 条义务即可 |
| 需要公开自己的源码吗？ | **不需要**（这正是 LGPL 与 GPL 的区别） |
| 该装什么？ | **`pip install PySide6-Essentials`**（不是 `PySide6`） |
| 绝对不能用什么？ | **Qt Charts、Qt Data Visualization、Qt Graphs、Qt Virtual Keyboard** —— GPL-only |
| 绘图怎么办？ | 用 **matplotlib**（BSD 风格许可），本软件已全部改为 matplotlib |
| 打包用什么？ | PyInstaller，**`--onedir`**（不是 `--onefile`），并排除 GPL 模块 |
| 要附带哪些文件？ | `licenses/LGPL-3.0.txt`、`licenses/GPL-3.0.txt`、`licenses/NOTICE.txt` |
| 一个坑 | **PySide6 的 wheel 不自带 LGPLv3 文本**，必须自己提供【本机实测】 |

## 1. 为什么换掉 PyQt5：许可模型完全不同

| | PyQt5 / PyQt6 | PySide6 |
| --- | --- | --- |
| 版权方 | Riverbank Computing | The Qt Company（官方） |
| 开源许可 | **GPL v3** 或商业许可 | **LGPLv3**（另有 GPLv3 / 商业） |
| 闭源分发 | ❌ GPL 传染，必须开源 | ✅ 满足条件即可闭源 |
| API | 与 Qt C++ 几乎一一对应 | 官方绑定，API 略有差异（`Signal/Slot`、`QAction` 在 QtGui 等） |

这是选择 PySide6 的**唯一原因**——功能上两者等价。

## 2. LGPLv3 的具体义务（闭源商用要做的 5 件事）

LGPLv3 的核心思想：**你改库 → 要开源库；你不改库、只是调用它 → 你的代码可以闭源**，
但必须让用户有能力替换这个库。

### 2.1 五条义务与落地做法

| # | 义务 | 具体做法 | SHKit 的做法 |
| --- | --- | --- | --- |
| 1 | **动态链接**（"suitable shared library mechanism"） | 以共享库形式调用，不静态链接、不并入自己的二进制 | Python 的 `import PySide6` 加载的是 `.pyd` + `Qt6*.dll` 共享库，属动态链接【本机实测：`PySide6/` 下是 `Qt6Core.dll`、`Qt6Widgets.dll` 等独立 DLL】 |
| 2 | **允许替换库**（relink） | 用户能换掉 Qt 库并重新运行 | 用 PyInstaller **`--onedir`**，Qt DLL 作为独立文件放在 exe 旁边，用户可直接替换 |
| 3 | **随附许可文本** | 提供 LGPLv3 全文（LGPLv3 以引用方式并入 GPLv3，故一并提供 GPLv3） | `licenses/LGPL-3.0.txt`、`licenses/GPL-3.0.txt` 已就位（取自 gnu.org 官方文本） |
| 4 | **显著声明** | 声明使用了该库及其许可 | `licenses/NOTICE.txt` + 软件「帮助 → 关于」对话框 |
| 5 | **不得增加额外限制** | 不得对用户行使 LGPL 权利施加限制（如 EULA 里禁止反向工程 Qt） | 若写 EULA，须保留用户替换 Qt 的权利 |

### 2.2 不需要做的事

- **不需要公开自己的源代码**（含 GUI 代码）。这对闭源商用是决定性的。
- **不需要公开构建脚本**（除非你修改了 Qt/PySide6 本身）。
- 只要不修改库本身，就不需要提供 Qt 的源码，**指向官方获取渠道即可**
  （即提供 `pip install PySide6-Essentials==6.8.3` 这条命令和 PyPI 链接，
  这就是"Minimal Corresponding Source"的务实做法）。

### 2.3 ⚠️ 修改 Qt 的后果

如果你修改了 PySide6/Qt 的源码（哪怕打补丁），**修改部分必须以 LGPLv3 公开**。
如果你 fork 了 PySide6，还要把 fork 的源码一起提供。SHKit **没有、也不应**修改 Qt。

### 2.4 LGPLv3 相对 LGPLv2.1 新增的两条

- **Anti-tivoization（§ Installation Information）**：对"User Product"（消费电子类设备），
  若你分发的组合作品中包含该库，需要提供安装信息以便用户安装修改后的库版本。
  **普通 PC 桌面软件不属于 User Product，通常不触发**；但若将来把 SHKit 做成
  锁定的仪器/一体机固件，这条就会生效。【待核对】
- **专利授权（§11）**：贡献者向使用者授予其必要专利许可；若你发起专利诉讼指控该作品，
  授权自动终止。对使用者是利好，无需额外动作。

## 3. Qt 模块的许可差异（最大的坑）

Qt 6 开源版**不同模块的许可不一样**。绝大多数是 LGPLv3，但有若干 **GPL-only** 模块：

| 模块 | 许可 | 能否闭源商用 |
| --- | --- | --- |
| QtCore / QtGui / QtWidgets / QtNetwork / QtSvg / QtXml / QtSql / QtConcurrent / QtPrintSupport / QtOpenGL / QtUiTools / QtTest / QtHelp | LGPLv3 | ✅ |
| **Qt Charts** | **GPLv3** | ❌ |
| **Qt Data Visualization** | **GPLv3** | ❌ |
| **Qt Graphs**（Qt 6.6+，Charts/DataVis 的继任者） | **GPLv3** | ❌ |
| **Qt Virtual Keyboard** | **GPLv3** | ❌ |
| Qt Safe Renderer | 商业许可 | 需购买 |
| Qt WebEngine | LGPLv3（但依赖复杂） | 一般可以，需单独评估 |

> 【待核对】具体到 6.8.3 的逐模块清单，建议到 Qt 官方许可页
> (`doc.qt.io/qt-6/licensing.html`) 再确认一遍；Qt 各版本的模块划分会变。

### 3.1 关键决定：只装 Essentials

- `PySide6`（完整元包）= `PySide6-Essentials` + `PySide6-Addons`
- **`PySide6-Addons` 里就包含 GPL-only 的 Qt Charts / Qt Data Visualization**

所以：

```bash
# ✅ 正确
pip install PySide6-Essentials

# ❌ 错误：会把 GPL-only 模块一起装进来
pip install PySide6
```

### 3.2 【本机实测】验证结果

在你这台机器上装 `PySide6-Essentials==6.8.3` 后逐个尝试导入：

```
QtCore / QtGui / QtWidgets / QtSvg / QtPrintSupport / QtNetwork / QtXml /
QtConcurrent / QtTest / QtOpenGL / QtUiTools / QtQml / QtQuick / QtSql /
QtHelp / QtDBus                                        → 可用（LGPLv3）

QtCharts / QtDataVisualization / QtMultimedia / QtWebEngineWidgets /
QtPdf / QtSerialPort / QtStateMachine                   → 不可用（ModuleNotFoundError）
```

即 **GPL-only 模块确实没有被安装进环境**。
（`PySide6/` 目录下能看到 `QtCharts.pyi` 这类文件，但那是**类型提示存根**，
不是可导入的模块、也不是 GPL 代码，无许可风险。）

### 3.3 【本机实测】PySide6 不自带 LGPL 文本

```
site-packages/PySide6_Essentials-6.8.3.dist-info/
    LicenseRef-Qt-Commercial.txt     ← 只有这一个
    （没有 LGPL-3.0 文本）
site-packages/shiboken6-6.8.3.dist-info/
    LicenseRef-Qt-Commercial.txt
```

**结论：分发 PySide6 时，LGPLv3 全文必须由你自己提供。**
本项目的 `licenses/LGPL-3.0.txt` 与 `licenses/GPL-3.0.txt` 已从 gnu.org 官方下载补齐。

## 4. 其它依赖的许可

| 组件 | 许可 | 闭源商用 |
| --- | --- | --- |
| numpy | BSD-3-Clause | ✅ |
| scipy | BSD-3-Clause | ✅ |
| **matplotlib** | PSF 风格 / BSD 兼容 | ✅ |
| pandas | BSD-3-Clause | ✅ |
| xarray | Apache-2.0 | ✅（需保留 NOTICE 中的归属声明） |
| netCDF4-python | MIT | ✅（底层链接的 HDF5/curl/zlib 各为 BSD 风格） |
| psutil | BSD-3-Clause | ✅ |
| **PyInstaller** | **GPL-2.0-or-later + 特殊例外** | ✅ **例外明确允许用它打包闭源程序** |
| Natural Earth 海岸线数据 | 公有领域 | ✅ |

**关于 PyInstaller**：它的主体是 GPL-2.0，但带一个明确的例外条款
（"special exception"），允许用它编译、链接、分发**非自由程序**——
即用 PyInstaller 打包闭源商业软件是被官方明确允许的，且 PyInstaller 本身
不随你的发行包分发（它是构建工具）。【通行做法；建议发行前在
`pyinstaller.org/en/stable/license.html` 再确认一次例外原文】

**关于 netCDF4**：Python 层是 MIT，但会动态链接 HDF5、libcurl、zlib。
这些库是 BSD 风格/公有领域许可，不构成闭源障碍。若采用 PyInstaller 打包，
它们会作为独立 DLL 一同分发，建议在 NOTICE 里一并声明。

**关于 matplotlib 字体**：matplotlib 自带的 DejaVu 字体是免费字体许可（可商用）；
本软件的界面中文依赖**系统字体**（Microsoft YaHei 等），不随包分发字体，
因此不涉及字体授权问题。

## 5. 打包与分发

### 5.1 推荐命令

```bash
pip install PyInstaller

pyinstaller --noconfirm --clean --windowed --onedir \
  --name SHKit \
  --exclude-module PySide6.QtCharts \
  --exclude-module PySide6.QtDataVisualization \
  --exclude-module PySide6.QtGraphs \
  --exclude-module PySide6.QtVirtualKeyboard \
  --exclude-module PySide6.QtWebEngineCore \
  --exclude-module PySide6.QtWebEngineWidgets \
  --exclude-module PySide6.QtMultimedia \
  --exclude-module PySide6.QtPdf \
  --exclude-module PySide6.QtQuick3D \
  --add-data "data;data" \
  --add-data "licenses;licenses" \
  --add-data "docs;docs" \
  shkit/gui/app.py
```

要点：

1. **`--onedir` 而不是 `--onefile`**。`--onefile` 会把所有东西压进一个 exe，
   运行时解压到临时目录再加载——用户实际上**无法替换 Qt 库**，
   与 LGPLv3 的 relink 要求相冲突，是社区公认的风险点【通行做法】。
   `--onedir` 下 Qt 的 DLL 就摆在 exe 旁边，用户可以替换，合规性明显更好。
2. **`--exclude-module` 主动排除 GPL-only 模块**，即使将来误装了完整版 PySide6
   也不会被打进包。
3. `--windowed` 不弹控制台窗口。

### 5.2 发行包目录结构

```
SHKit/
├─ SHKit.exe
├─ _internal/                 ← PyInstaller 的运行时 + Qt DLL（用户可替换）
│   └─ PySide6/Qt6*.dll
├─ data/                      ← 勒夫数表 + 离线海岸线
├─ docs/                      ← 使用说明、方案调研、许可说明
└─ licenses/
    ├─ LGPL-3.0.txt           ← Qt / PySide6 的许可（必带）
    ├─ GPL-3.0.txt            ← LGPLv3 引用的 GPLv3（建议一并带）
    └─ NOTICE.txt             ← 第三方组件与版权声明（必带）
```

### 5.3 发行前自查清单

- [ ] 环境里只有 `PySide6-Essentials`，没有 `PySide6-Addons`
- [ ] 代码中**没有** `import PySide6.QtCharts` / `QtDataVisualization` / `QtGraphs`
      （可用下面第 7 节的自检脚本确认）
- [ ] 发行包内含 `licenses/LGPL-3.0.txt`、`licenses/GPL-3.0.txt`、`licenses/NOTICE.txt`
- [ ] 「关于」对话框里写明了使用 PySide6/Qt 及 LGPLv3
- [ ] 用 PyInstaller `--onedir` 打包，Qt DLL 是独立文件
- [ ] 若写了 EULA，其中**没有**限制用户替换 Qt 库的条款
- [ ] 没有修改过 PySide6 / Qt 的源码

## 7. 自检脚本

把下面这段存成 `check_licensing.py` 并在**正式打包用的那个环境**里跑一次：

```python
import importlib, sys

GPL_ONLY = ["QtCharts", "QtDataVisualization", "QtGraphs",
            "QtVirtualKeyboard", "QtQuick3D"]
LGPL_OK = ["QtCore", "QtGui", "QtWidgets", "QtSvg", "QtNetwork",
           "QtPrintSupport", "QtSql", "QtXml", "QtConcurrent", "QtOpenGL",
           "QtUiTools", "QtTest", "QtQml", "QtQuick", "QtHelp"]

print("Python:", sys.version.split()[0])
try:
    import PySide6
    print("PySide6:", PySide6.__version__)
except ImportError:
    print("PySide6 未安装"); sys.exit(1)

bad = []
for m in GPL_ONLY:
    try:
        importlib.import_module(f"PySide6.{m}")
        bad.append(m)
    except ImportError:
        pass

ok = 0
for m in LGPL_OK:
    try:
        importlib.import_module(f"PySide6.{m}"); ok += 1
    except ImportError:
        pass

print(f"可用的 LGPL 模块: {ok}/{len(LGPL_OK)}")
if bad:
    print("❌ 检测到 GPL-only 模块，闭源分发有风险:", bad)
    print("   请 pip uninstall PySide6 PySide6-Addons && pip install PySide6-Essentials")
    sys.exit(1)
print("✅ 未检测到 GPL-only 模块：当前环境可用于闭源分发")
```

## 8. 常见误区

| 误区 | 事实 |
| --- | --- |
| "LGPL 就是 GPL，不能闭源" | 错。LGPL 专为"闭源程序链接开源库"设计，不改库就不用开源 |
| "Python 里 import 不算链接，所以无所谓" | 错。加载 `.pyd`/`.dll` 就是动态链接，LGPL 义务随之生效（但**正是这种链接方式**让闭源成为可能） |
| "装完整的 PySide6 更方便" | 会带上 GPL-only 的 Qt Charts/DataVisualization，闭源路断 |
| "PyInstaller 是 GPL，打包出来就得开源" | 错。有明确例外允许打包闭源程序 |
| "用 PyQt5 只要标注一下就行" | 错。GPL 要求**你的整个程序**以 GPL 发布，除非买 Riverbank 的商业许可 |
| "PySide6 包里有 LGPL 文本" | **本机实测：没有**，必须自己补 |
