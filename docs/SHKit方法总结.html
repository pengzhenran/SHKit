1. 文档目的与核心结论

本文说明 SHKit 把「散点/网格 → 球谐系数」这件事做成了什么，重点回答三个问题： 每个方法最小化的目标函数是什么、它在什么条件下才成立、什么时候它会给出 看起来正确但物理上错误的结果。全部结论都附有本机实时计算的数值与图。

核心结论速览（只读这一段也够）

  1. 两个目标函数的定义域不同，这是全部问题的根源。零填充全球 L2 投影的积分域是 整个球面（区域外 f≡0 也进入目标函数）；加权最小二乘的求和域只有测点。 二者仅在采样构成有效求积规则（K≈I）时才等价。
  2. 区域数据上“迭代把重建误差压到零”不是成功，而是警报。长江掩膜实测：求积残差 9.9966e-01（这就是截断泄漏），而 CG 收敛后残差塌到 7.162e-06，同时 C00 从几何真值 2.0680188857e-06 膨胀到 2.376430e-02，即 11,491.3 倍， 隐含 1-set 面积 12,148,497 km²（比中国还大）。
  3. 对 0/1 指示场，C00 是几何事实，不是自由参数。它必须等于 "为 1 的面积占比”。长江掩膜的三套积分元给出三套答案，只有 lattice 是对的： 2.0680188857e-06（1,057.19 km²）； grid 偏大 4.59%； delaunay 用球面凸包，偏大 69.98 倍。
  4. 积分元选错不只是“尺度偏一个常数”。grid 与 lattice 的逐点权重比 在 44 个点上超过 1.1 倍、最大 5e+03 倍，std/mean = 13.6；所以重建的形状也变 （L=12 图样相关 0.986068）。
  5. 截断泄漏有硬地板，迭代算法尊重它。全球 0/1 帽（覆盖率 1.000000）实测 L=2..40 的残差 0.1343/0.1073/0.06365/ 0.06003/0.04541/0.03257， 加 3 次甚至 25 次迭代一位都不动。区域数据上残差却塌向零——差别就在这里。
  6. 区域数据本质上是可解性问题，不是积分元问题。未正则化的区域求解必须避免： 30° 球冠实测条件数 5.52e+16、系数相对误差 146.4（完全失效）；kaula 正则或 Slepian 才对。

约定：下文所有“覆盖度"= Σw/4π；"Shannon 数"= (L+1)²·覆盖度； "区域外场量"= 区域外重建 RMS 与区域内重建 RMS 之比。符号 Cnm/Snm 指 4π 归一化的实球谐系数。

2. 数学基础

2.1 展开式

f(θ,λ) = Σn=0..N Σm=0..n P̄nm(cos θ) [ Cnm cos(mλ) + Snm sin(mλ) ]
P̄ 为 4π 归一化连带 Legendre 函数，无 Condon-Shortley 相位； Sn0 ≡ 0（sin 0λ = 0），因此非平凡系数共 (N+1)² 个。

归一化定义：(1/4π) ∫Ω P̄nm² cos²(mλ) dΩ = 1。 与 SHTOOLS 的 norm=1, csphase=1 一致，也与 m2py / gridSHconvert 的三角布局兼容。

2.2 正变换（分析）

Cnm = (1/4π) ∫Ω f(θ,λ) P̄nm(cos θ) cos(mλ) dΩ
Snm = (1/4π) ∫Ω f(θ,λ) P̄nm(cos θ) sin(mλ) dΩ

离散化后就是加权投影 x = (1/4π) AᵀWf。注意分母恒为 4π（全球归一化）， 而 W 必须是真实的面积元——这一条决定了区域数据上 C00 对不对。 若把 W 强行归一化到 Σw = 4π，等于把系数整体乘上 4π/Σw，C00 随之失去几何含义。

2.3 反变换（综合）

把同一组系数代回 2.1 的展开式。SHKit 里 synthesize() 在给定点上求值， synthesis_grid() 在规则网格上求值（分块，避免一次性构造 N×N 的中间量）。

2.4 逐阶功率与 Parseval

逐阶功率 Pn = Σm=0..n ( Cnm² + Snm² )   ⟹   Σn Pn = (1/4π) ∫Ω f² dΩ

本机校验（L=8，GLQ 精确求积网格 153 点）：ΣPn = 2.809570980632e+00， (1/4π)∫f²dΩ = 2.809570980632e+00，相对差 0.0e+00。Parseval 是精确恒等式，与采样密度无关。

2.6 Shannon 数与覆盖度

覆盖度 c = Σw / 4π      Shannon 数 NSh = (L+1)² · c

NSh 是一个区域在给定阶数下能承载的独立自由度数。它同时也是完备性矩阵 K 的迹：Σλ(K) = (L+1)²·c。本机在长江掩膜 L=12 上实测 Σλ = 3.4949519168e-04，Shannon 数 = 3.4949519168e-04，比值 1.000000000000—— 这条恒等式可当自检用。

NSh ≪ 1 时，截断后掩膜的峰值只能到 NSh 量级。 长江掩膜 L=12 的 NSh = 3.4950e-04，实测峰值 3.4555e-04，比值 0.9887。 要让掩膜“立”到 1，需 L ≈ 694.4。

3. 积分元（权重规则）

积分元 wi 是“每个样本代表多大立体角”。它决定了 Σw（⇒ 覆盖度 ⇒ C00）以及每个点在目标函数里的份量。选错规则不会报错，只会给出一组自洽但 物理错误的结果。

4. 估计方法：目标函数与适用条件

这是全文重点。SHKit 有 5 条估计路径加 2 种正则化、1 个 Slepian 分支。 先说它们之间的关系，因为不理解这一点就会以为“迭代能把误差压小”。

4.1 统一视角：三种停止策略，同一个估计量

设 A 为设计矩阵（N×(L+1)²），W = diag(wi)，定义完备性矩阵

K = (1/4π) AᵀWA    ⟹    K = I ⟺ 采样 + 权重构成精确求积规则

三条路径其实是同一个正规方程 (AᵀWA)x = AᵀWf 的三种停止策略：

路径 公式 等价说法
quadrature / projection x = (1/4π)AᵀWf 正规方差的第 0 步
iterative x ← x + (1/4π)AᵀW(f − Ax) 提前停止的 Richardson/Landweber 迭代 = 隐式正则化
wlsq / cg x = (AᵀWA)−1AᵀWf 正规方程的极限解；K 亏秩时 = 最小范数解

K ≈ I 时三者数值等价；K 远离 I 时它们分道扬镳，而收敛极限是三者里唯一没有物理依据的 那个。长江案例正是后者。

4.2 quadrature / projection：零填充全球 L2 投影

mindeg≤L ∫Ω ( f − A x )² dΩ     Ω = 整个球面，f = 区域外 0   ⟹   x = (1/4π) AᵀWf （W 取几何和，不归一化到 4π）

因为区域外 f ≡ 0 对分子无贡献，而分母 4π 是全球归一化，所以这个投影恰好是 零填充场的 L2 投影。它的三条性质：

  • 样本残差就是截断泄漏，停在由 L 决定的地板上，永远压不到零；
  • C00 精确等于面积占比（几何事实）；
  • 不做任何反演，因此没有近零空间放大。

长江 L=12 实测：C00 = 2.0680188857e-06 （几何要求 2.0680188857e-06，比值 1.000000000000）， 残差 9.996580e-01，面积加权残差 9.996581e-01。 quadrature 与 projection 在同样的几何权重下逐位相同 （相对差 0.000e+00）——它们本来就是同一件事。

可选采样偏差校正 τ（仅 projection）：把 K 特征分解 （特征向量即 Slepian taper，特征值 λ 即集中因子），只对 λ ≥ τ 的方向除以 λ， 其余保持不变。τ = 1 等于纯投影；τ → 0 退化成未正则化 WLSQ。 校正的是采样偏差（可修的离散化误差），从不碰截断泄漏。

4.5 wlsq / cg：逐点加权最小二乘

min ‖√W (A x − f)‖² = Σi=1..N wi ((Ax)i − fi)²   求和域只有测点

两条重要性质，决定了它什么时候会骗你：

  • 求和域是测点集：隐含的 0 不在目标函数里，所以它对“掩膜是否被还原”结构性失明。
  • 目标函数对 W 的整体缩放不变：φ(cW) 与 φ(W) 极小点相同。而指示场的正确 C00 恰恰正比于 Σw——目标函数扔掉的正是确定 C00 所需的那条信息。

4.7 slepian：区域数据的正解

核心洞察：Slepian 集中矩阵就是 K。在正交归一的 taper 基下，区域加权最小二乘的 正规矩阵是对角的：

sα = tαᵀAᵀWf / (4π λα),    c = Σα sα tα   只有 λα ≈ 1 的 taper 可用，截断本身就是正则化

本机实测（25° 球冠，186 点，L=20， 覆盖度 0.0424，λ>0.5 共 17 个 taper）：

低阶场本身就弥散在全球，其集中因子恰好接近面积占比 A/4π，远低于 0.5；能集中的 taper 都落在高阶。所以用区域数据反演低阶全球场在信息论上不成立，正确做法是 remove–restore：先用全球模型扣掉长波，只在区域内分析残差，最后加回。

聚簇 3000 点（70% 在 35° 帽） 3,000 1.262e-01 wlsq

本轮修改后的行为：区域覆盖（覆盖度 < 0.999）→ 路由到 projection，不再升级为 wlsq/cg。原因是区域覆盖下 正规矩阵在双精度下已经奇异（长江实测 -4.24e-20 的最小特征值），升级到最小二乘只会返回近零空间的 最小范数解。

5. 诊断量与守卫

诊断量 含义 判据阈值 该采取的动作
max|K−I|（gram_deviation） K = AᵀWA/4π 偏离单位阵的最大量；K=I 才是精确求积 < 1e-2 允许直接求积 超标且覆盖全球 → 换 WLSQ + 正则；覆盖区域 → 不要反演 K
coverage Σw/4π，数据覆盖球面的比例 < 0.999 判为区域数据 区域数据按目标 A 走 projection；要目标 B 就正则化 / Slepian / remove-restore
condition_number cond(A√W) > 1e8 双精度耗尽 降阶、提高超定比、或给正则化
overdetermination N/(L+1)² < 2 勉强定解；推荐 ≥ 4 降 nmax，或增加数据
shannon (L+1)²·coverage，区域能承载的自由度 < 0.5·系数数 ⇒ 该区域撑不住这个阶数 降阶，或改用 Slepian；记住峰值上界就是这个数
lmax_recommended 当前采样能支持的最大阶数（计数上限） 覆盖 ≪ 1 时只是计数上限，不是有效约束 配合 Shannon 一起看
residual_rms_weighted（新增） 面积加权的残差 RMS——球面上的真 L2 范数 与未加权值并列显示 两者差别大时说明采样在球面上不均匀（如经纬网格极区过采样）
C00 一致性守卫（新增） C00 必须等于 Σwf/4π（场的全球均值；任何阶截断都保持它） 相对偏离 > 10% 报警 检查积分元与 normalise；改用 projection。小的样本残差不能作为辩护
残差塌陷告警（新增） wlsq/cg/iterative + 覆盖度 < 0.999 + 相对残差 < 1e-3 三者同时满足即报警 说明求解器利用了近零空间，不是拟合得好；与 projection 对照并检查 C00

6. 算法与实现

环节 实现要点 复杂度 / 内存
流式 m 阶求积 沿阶 m 逐列推进，只保留当前与 m−2 列，不构造 N×N 中间量 O(N·(L+1)²) 时间，O(N·L) 内存

Kaula 谱先验 由一次快速求积得到逐阶振幅 sn，量纲无关 额外一次求积

11. 优缺点与适用场景汇总

quadrature / projection（零填充全球投影）

优点：目标函数定义在整个球面上，因此样本残差就是截断泄漏；C00 精确 等于面积占比；不做反演，没有近零空间放大；计算最便宜。

缺点/边界：不能修采样偏差（需靠 τ 或换权重规则）；不给出“区域内最优拟合”， 所以区域内的拟合看起来“很差”——但那是真的。

什么时候会骗你：几乎不会骗；它的问题是被误读——把 0.99 的残差当成“方法失败”。 真正的失败是换个方法把残差压到 1e-6。

iterative（Richardson 校正）

优点：准均匀采样下极便宜地逼近最小二乘（实测 6.344e-04 → 2.784e-06）。

缺点/边界：niter 必须小；不动点是 WLSQ 解，所以在 K 远离 I 的数据上 它会一路上滑到错误解。

什么时候会骗你：区域数据上它每一步都在降残差，看起来在改进， 而 C00 同时单调膨胀（niter 0→25 从 1.0× 到 25.9×）。

wlsq / cg（逐点加权最小二乘）

优点：全球覆盖但采样不规则时的正解；配合超定比 ≥ 4 与正则化很稳。

缺点/边界：目标函数求和域只有测点，对“隐含 0"结构性失明；对 W 整体缩放不变， 因此原则上无法约束 C00。

什么时候会骗你：区域数据上未正则化时——cg_info=0（报告成功收敛）、 残差 7.3e-06、而 C00 错 11,516 倍。 它不会报错，只会给一个自洽但物理上不可能的解。

reg='tikhonov'

优点：实现简单，先验明确（最小范数）。

缺点：在零空间极大的区域问题上几乎不起作用——长江上 α 到 1e-4 仍停在 2.376e-02； 30° 球冠上加 α=1e-9 后系数相对误差仍 12.572。

reg='kaula'

优点：量纲无关（谱先验由数据自估），对区域数据有效：长江 C00 拉回 3.432e-07（隐含 175 km²）。

缺点/边界：先验本身取自一次求积的逐阶振幅，覆盖不全或有噪声时先验会被污染； α 仍需人工判断。

slepian

优点：区域数据的正解——把病态显式化（λ 就是集中因子）， 条件数与区域外场量都低几个数量级（1.51 / 4.02e-02 vs 3.29e+12 / 8.9）。

缺点/边界：区域内拟合“一般”（它放弃了不可确定的方向）； 小区域连低阶场都恢复不了，必须 remove–restore。

积分元规则

lattice：格点数据上唯一正确；grid 只在完整网格上正确； delaunay 拿凸包面积，对河网状掩膜虚高 ~70 倍； voronoi 对任何区域子集都绝对错误（恒为 4π）。

13. 已知限制

  1. 命名问题（未改）：新规则名 lattice 与 shkit/cli.py 里已有的 "Fibonacci lattice"（指全球准均匀点列， fib_sphere() 的 docstring）撞名，且与 grid 在英文里近乎同义。 二者靠名字本身区分不出“完整 vs 有洞”。候选改名 subgrid （与 grid 的关系一目了然，不引入新术语）。本轮未改，以免动到已发布的规则名。
  2. SHCoeffs.degree_rms() 在 n=0 处偏小 √2 倍（既有行为，未改）： 它对 n=0 也是 mean([C00², S00²])，而 S00 结构上恒为 0， 所以返回的是 |C00|/√2。本文档 9.3 的逐阶谱表沿用该既有行为 （n=0 行 = 1.462310e-06，而 C00 = 2.068019e-06， 比值为 0.707107 ≈ 1/√2）。 其余各阶不受影响。修它会改变所有导出谱与既有测试基线，故未在本次范围内改动。
  3. C00 守卫抓不到口径错误：它检查的是求解器产出的 C00 与 Σwf/4π 是否一致。若积分元本身选错（如 delaunay 凸包面积），解仍然自洽， 守卫不响。9.2 的表就是这种情形（四套口径全部“自洽”）。
  4. τ 校正需要构造 K：projection(tau=...) 需要完整设计矩阵， 内存约 O(N·ncoef)；长江（142846 × 169）约 193 MB，可接受，但更大的问题要小心。
  5. 读取 .gfc 的头部元数据不落到 coeffs.meta 顶层： 方法/积分元等写在 meta['gfc_header'] 里（键值为字符串）， 需要 c.meta['gfc_header']['method'] 才能取到。 本文档 9.5 即按此读取。
  6. netCDF 无法在本机共享盘上写入：netCDF4 在 华为家庭存储（SMB）上对任何路径 to_netcdf() 都报 PermissionError；本机临时目录正常。因此 tests/run_all.py 中 3 项 .nc 相关检查失败 （grid nc round trip、synth 写 recon.nc、 glq-grid 写 glq.nc），与本轮改动无关。 .grd/.csv 往返均通过。故本文档所有产物只用 PNG/CSV/JSON。
  7. 区域低阶反演在信息论上不成立：这不是软件限制而是数学事实 （4.7 的小球冠表）。任何声称“用区域数据反演出低阶全球场”的结果都需要先做 remove–restore，否则不可信。
  8. 本轮未覆盖：FFT/局部球谐等更快的高阶路径；多时次数据上的 C00 守卫 只对第 0 个时次给出标量判定（其余时次在 meta['dc_mean_expected_all'] 里）。
