## 积分元

每个点代表一个 `Δlon × Δlat` 的球面格：

```
w_i = Δlon_rad · (sin φ_hi − sin φ_lo)          [立体角 sr]
```

`Δ` 由数据本身稳健估计（不用硬编码）。与作者 `calParea.m` 的平面近似
（`dlat·dlon·cosφ` × 椭球边长）相比，球面精确面积相对差 **6.7e-12**，量级完全一致。

用作者的 `dlon = dlat = 0.00083` 复跑：`C[0,0]` 差 **0.6115%**，且**整条谱的相对差
也正好是 0.6115%** —— 纯比例因子，说明两套算法等价，差别只在他把格距写死成
0.00083（比实测小 0.6%）。要复现他的数值就加 `--cell 0.00083`。

### 库里的对应规则：`rule='lattice'`

上面的手算积分元已经固化进库，`rule='auto'` 对这类数据会自动选中它：

```bash
shkit analyze --points Yangtze_River.txt --nmax 12 --method projection
# 报告里会写 weight rule = 'lattice'
```

复现校验：`lattice` 与 `yangtze_points_weights.csv` 的 `Σw` 相对差 **2e-15**
（逐点最大相对差 2.8e-13，纯粹是那个 CSV 只写了 12 位有效数字），
`C[0,0] = 2.0680188857e-06` 与之逐位一致。

别用 `grid`，也别用 `delaunay`：

| 规则 | Σw | 面积 | C00 | 说明 |
| --- | --- | --- | --- | --- |
| **`lattice`** | 2.598749175508e-05 | **1057.19 km²** | **2.0680188857e-06** | 每点一个格元，Σw = 点数 × 格元面积（精确） |
| `grid` | 2.718054234939e-05 | 1105.72 km² | 2.1629588354e-06 | **偏大 4.59%**：格边取在相邻**现存**坐标的中点，紧邻缺行的点于是吞掉了那个空档的一半 |
| `delaunay` | 1.818723665645e-03 | 73986.81 km² | 1.4472943076e-04 | 球面**凸包**面积，偏大 **67 倍** |

`grid` 的偏差不是纯比例：142846 点里有 44 个（0.031%）因为挨着 12 条最宽达 83 步的
纬度空档，权重最多虚高 **5362 倍**，所以连重建的**形状**都会变（L=12 时两者图样相关
0.9861）。这份数据的格网是"有洞的规则格网"，只有 `lattice` 的口径是对的。

## 「对应空间分辨率的球谐阶数」是多少

两个方向、两个数量级完全不同的答案：

### 正变换（散点/掩膜 → 系数）：由**你要分辨的特征尺度**定

半波长 `= πR/n`：

| 特征尺度 | 长度 | 对应阶数 |
| --- | --- | --- |
| 采样点间距 | 0.09 km | 216208 ← 不可行、无意义 |
| 长江主槽宽度（约） | 1 km | 20038 ← 不可行 |
| 水体等面积圆直径 | 36.7 km | 546 |
| 区域短边 | 254.6 km | **78.7** |
| 矩形等面积圆直径 | 396.9 km | **50.5** |
| 边长几何平均 | 351.8 km | **57.0** |
| 外接矩形对角线 | 548.6 km | **36.5** |

→ 想表达**区域尺度**的东西：**n ≈ 40–80，取 60**（半波长 333.6 km ≈ 区域尺度）。
这也正是作者取 `maxSHod = 60` 的原因。

→ 想让**掩膜本身**立起来（区域内 ≈1）：见下。

### 硬约束：Shannon 数（实测验证）

区域能承载的独立自由度 `N ≈ (L+1)² · Ω/4π`，Ω/4π = 2.068e-6：

| L | 自由度 | Shannon 数 | 半波长 | 实测掩膜峰值 | 峰值/Shannon |
| --- | --- | --- | --- | --- | --- |
| 30 | 961 | 1.99e-3 | 667 km | 0.0019 | 0.94 |
| 60 | 3721 | 7.70e-3 | 334 km | 0.0060 | 0.79 |
| 120 | 14641 | 3.03e-2 | 167 km | 0.0136 | 0.45 |
| 240 | 58081 | 1.20e-1 | 83 km | （未测） | — |
| 480 | 231361 | 4.78e-1 | 42 km | （未测） | — |
| 700 | 491401 | **1.02** | 29 km | — | — |

**结论：**
- `L = 60` 时截断掩膜的峰值只有 **0.006**（不是 1），与 Shannon 数 0.0077 吻合 →
  它是一条**区域平均核**，不是掩膜。
- 想让掩膜峰值到 1，需要 `N ≈ 1` → **L ≈ 694**（半波长 29 km），共 483025 个系数。
  用现在的直接求和约需 **40+ 分钟**；更高阶必须换算法（Slepian / FFT / 局部）。
- 反方向（水位场 → 系数 → 解释）则**无论多少阶都不可反演**：`N ≪ 1` 说明这块区域
  只能支撑不到一个独立自由度。要做区域反演得用
  `shkit.slepian_analysis()`，由它给出真正可用的自由度个数。

```bash
       --values CH --epoch 0 --lmax 60
```

## 该用多少阶？一条命令

```bash
shkit nmax --coeffs examples/yangtze_mask_n60.sh
```

输出会同时给出三个**互相独立**的约束：

```
① 截断（数据带宽）：保留功率比 → 重建误差 = sqrt(1−保留比)   ← Parseval，精确
       nmax=12  保留  6.76%   误差 9.66e-01
       nmax=30  保留 34.82%   误差 8.07e-01
       nmax=60  保留100.00%   误差 0.00e+00
   ⚠ 在 ≤60 阶内没有更小的阶数能把误差压到 1% 以内（谱太宽）
② 采样/覆盖：lmax_recommended（覆盖≪1 时只是计数上限，不是有效约束）
③ 区域：Shannon = (L+1)²·2.068e-6 = 7.70e-3 ≪ 1 → 要让 Shannon≈1 需 nmax≈695
   → ①与③冲突：数据本身不支持你要的分辨率，该用 Slepian
```
